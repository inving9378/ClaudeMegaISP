# Dashboard
**En pocas palabras:** Pantalla de inicio que muestra información operativa clave.

## Para qué sirve
- Proporciona un resumen rápido del estado de clientes, tickets y finanzas.
- Permite fácil acceso a notificaciones y actividades recientes.
- Muestra indicadores de salud del servidor y módulos activos.
- Se adapta al perfil de usuario mostrando solo los datos relevantes.

## Pantallas
- [Dashboard](/) — Muestra widgets con información relevante según los módulos habilitados.

## Cómo se hace
### Acceder al Dashboard
1. Inicie sesión en el sistema MegaISP con sus credenciales.
2. El sistema redirige automáticamente al Dashboard.

## Qué datos pide
No hay datos que se ingresen directamente en esta pantalla.

## Quién lo usa
Lo utilizan administradores, supervisores y personal operativo que necesita monitorear el estado del negocio.
