# Módulo Voice
**En pocas palabras:** Es el conector del sistema con el servicio telefónico.

## Para qué sirve
- Facilita la conexión del sistema con el conmutador telefónico.
- Centraliza la gestión de la troncal de voz.
- Reporta el estado de conexión de la troncal para otros módulos.

## Cómo se hace
### Configurar la troncal telefónica
1. Se hace en [Pantalla de configuración de VoIP](/cobranza/voip).

## Quién lo usa
Este módulo es utilizado por administradores y por otros módulos que necesitan servicios de telefonía.
