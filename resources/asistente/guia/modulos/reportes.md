# Reportes
**En pocas palabras:** Permite consultar y exportar reportes operativos y novedades del sistema.

## Para qué sirve
- Generar informes operativos sobre el estado del ISP.
- Exportar datos del sistema en formatos como CSV o Excel.
- Mostrar el historial de actualizaciones del sistema (release notes).
- Filtrar y segmentar reportes según distintos parámetros.

## Cómo se hace
### Acceder al módulo de Reportes
1. Ingresar al sistema con credenciales de usuario habilitado.
2. Desde el menú lateral, ubicar el grupo **Addon**.
3. Dentro del grupo, seleccionar **Reportes**.

## Qué datos pide
### Alta de reportes (Reportes)
- **Obligatorios:** Tipo de reporte, Fecha desde, Fecha hasta.
- **Opcionales:** Estado del cliente, Zona / Sector, Formato de exportación, Versión del sistema, Fecha de publicación.
- **Se llenan solos:** Ninguno.

## Quién lo usa
Este módulo es utilizado principalmente por supervisores, administradores de sistema y personal de soporte que requieren visibilidad del estado operativo.
