# Módulo Hub
**En pocas palabras:** Es el lugar donde se gestionan las contraseñas de servicios externos.

## Para qué sirve
- Centraliza la gestión de contraseñas de diferentes proveedores.
- Permite ver y validar las contraseñas de manera sencilla.
- Facilita la rotación y auditoría de las contraseñas en un solo lugar.

## Cómo se hace
### Alta de integración
1. Se hace en la pantalla donde se gestionan las integraciones.

## Qué datos pide
### Alta de integración
- **Obligatorios:** Slug, Nombre, Type 
- **Opcionales:** (ninguno)

### Alta de proveedor
- **Obligatorios:** Provider, Slug, Nombre 
- **Opcionales:** (ninguno)

## Quién lo usa
El personal que trabaja en el área de desarrollo y gestión de integraciones con servicios externos.
