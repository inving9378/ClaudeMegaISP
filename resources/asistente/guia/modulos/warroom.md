# War Room
**En pocas palabras:** Es la sala de juntas digital para monitorear el negocio en tiempo real.

## Para qué sirve
- Ayuda a la dirección a mantener el control y enfoque durante las juntas operativas.
- Permite visualizar KPIs de diferentes áreas y gestionar el tiempo de la agenda.
- Facilita la creación de tareas asignadas, con recordatorios automáticos.
- Captura notas y acuerdos durante la junta para no perder información importante.
