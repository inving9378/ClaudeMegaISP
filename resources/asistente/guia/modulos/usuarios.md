# Usuarios
**En pocas palabras:** Administración de cuentas de acceso y roles del personal en MegaISP.

## Para qué sirve
- Crear, editar y bloquear cuentas de personal en el sistema.
- Asignar roles y permisos específicos a cada usuario.
- Controlar el acceso del equipo a diferentes secciones del sistema, garantizando que solo vean lo que les corresponde.

## Pantallas
- [Administración](/administracion) — Aquí se gestiona todo lo relacionado con las cuentas de usuarios.

## Cómo se hace
### Alta de usuario
1. Ir a la pantalla [Administración](/administracion) y seleccionar la opción para crear un nuevo usuario.

## Qué datos pide
### Alta de usuario ([Administración](/administracion))
- **Obligatorios:** Nombre, Apellido paterno, Apellido materno, Correo, Teléfono, Address, City municipality, State country, Code postal, Rfc, Login user, Password
- **Opcionales:** (ninguno)

## Quién lo usa
Usado principalmente por el administrador del sistema o personal con perfil de supervisión para gestionar las cuentas de acceso.
