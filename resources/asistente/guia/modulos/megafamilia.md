# MegaFamilia
**En pocas palabras:** Control parental para gestionar el uso de internet de los hijos.

## Para qué sirve
- Supervisa y restringe la actividad en línea de los hijos desde una app móvil.
- Permite gestionar licencias por plan de internet y crear perfiles para cada hijo.
- Establece reglas de contenido, geocercas, alertas y tareas familiares como incentivos.
- Ofrece un servicio de valor agregado que mejora la experiencia de los clientes.
