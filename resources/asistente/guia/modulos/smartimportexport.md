# Importación y Exportación de Datos
**En pocas palabras:** Herramienta para cargar o descargar grandes volúmenes de datos desde o hacia el sistema.

## Para qué sirve
- Permite importar grandes archivos de datos sin necesidad de ingresarlos uno por uno.
- Facilita la exportación de datos seleccionados a diferentes formatos (SQL, JSON, XLSX).
- Registra cada operación de importación y exportación para auditoría.

## Cómo se hace
### Importar datos
1. Ve a la pantalla de importación y selecciona el archivo a importar.

### Exportar datos
1. Ve a la pantalla de exportación y selecciona los módulos que deseas exportar.

### Consultar historial de importaciones y exportaciones
1. Accede a la pantalla de historial para revisar las operaciones realizadas.

## Qué datos pide
### Alta de importación (Pantalla de importación)
- **Obligatorios:** Archivo (formato .sql o .zip)
- **Opcionales:** Ninguno
- **Se llenan solos:** Ninguno

### Alta de exportación (Pantalla de exportación)
- **Obligatorios:** Módulos a exportar
- **Opcionales:** Ninguno
- **Se llenan solos:** Ninguno

## Quién lo usa
Personal de soporte y administración que necesita manejar grandes volúmenes de datos de manera eficiente.
