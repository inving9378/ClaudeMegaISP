# Asistente IA
**En pocas palabras:** Es un chat de inteligencia artificial para el equipo interno.

## Para qué sirve
- Proporciona un asistente conversacional para resolver preguntas.
- Organiza proyectos, tareas y notas de trabajo.
- Permite guardar y reutilizar prompts.
- Centraliza la gestión de credenciales de proveedores de IA.
