# Guías por módulo

Para dudas de un módulo, pide su guía con `consultar_guia` (tema `modulos/<nombre>`). Cada guía trae
sus pantallas con enlace, cómo se hacen las tareas y qué datos pide cada alta. Si existe una guía revisada
por el equipo del mismo tema (clientes, pagos-y-facturacion, tickets, red-y-equipos), esa manda en cómo se
hacen las cosas; pero para **qué datos pide** una pantalla usa siempre la guía `modulos/<módulo>`.

- `modulos/auditoria` — **Auditoría**: Es el historial que registra cambios en el sistema.
- `modulos/clientes` — **Clientes**: Gestiona la información integral de los clientes activos del ISP.
- `modulos/cobranzablaster` — **CobranzaBlaster**: Sistema de llamadas automáticas para cobrar cuentas pendientes.
- `modulos/configuracion` — **Configuración**: Ajustes globales del sistema MegaISP.
- `modulos/crm` — **CRM**: Es la herramienta para gestionar prospectos y clientes del ISP.
- `modulos/dashboard` — **Dashboard**: Pantalla de inicio que muestra información operativa clave.
- `modulos/documentacion` — **Documentación**: Es el manual interno del sistema para el equipo de MegaISP.
- `modulos/documentacioncorporativa` — **Documentación Corporativa**: Gestiona la información corporativa en 14 apartados.
- `modulos/documentos` — **Documentos**: Centraliza la administración de plantillas de documentos como contratos y recibos.
- `modulos/domiciliacion` — **Domiciliación**: Permite cobrar automáticamente la mensualidad al cliente a través de su tarjeta.
- `modulos/embajadores` — **Programa de Embajadores**: Incentiva a los clientes a referir nuevos usuarios a cambio de recompensas.
- `modulos/evaluadorempresarial` — **Evaluador Empresarial**: Es un cuestionario en línea para que empresas evaluen sus necesidades de conectividad.
- `modulos/finanzas` — **Finanzas**: Módulo central para la gestión económica del ISP.
- `modulos/flotas` — **Flotas**: Gestión de la flota vehicular de la empresa y de clientes ISP.
- `modulos/gestionred` — **Gestión de Red**: Es el panel donde se controlan routers, OLTs y se organizan direcciones IP.
- `modulos/hub` — **Módulo Hub**: Es el lugar donde se gestionan las contraseñas de servicios externos.
- `modulos/ia` — **Asistente IA**: Es un chat de inteligencia artificial para el equipo interno.
- `modulos/inventario` — **Inventario**: Módulo para el control y seguimiento del inventario de equipos y materiales del ISP.
- `modulos/localizacion` — **Localización**: Es el catálogo de estados, municipios y colonias de México, así como de sucursales y ubicaciones de la empresa.
- `modulos/manual` — **Manual de Usuario**: Es la documentación que explica el funcionamiento del sistema MegaISP.
- `modulos/mapas` — **Mapas**: Módulo para visualizar y gestionar la infraestructura de red del ISP en un mapa.
- `modulos/marketing` — **Marketing**: Módulo automatizado para la gestión de campañas de marketing.
- `modulos/megafamilia` — **MegaFamilia**: Control parental para gestionar el uso de internet de los hijos.
- `modulos/mensajes` — **Mensajes**: Módulo para gestionar correos y recordatorios automáticos de cobro.
- `modulos/payments` — **Pagos y Conciliaciones**: Maneja la recepción y aplicación de pagos de clientes.
- `modulos/planes` — **Planes**: Es el catálogo de servicios contratables que Meganet ofrece a sus clientes.
- `modulos/portalcliente` — **Portal Cliente**: Es la oficina virtual donde los clientes pueden realizar diversas gestiones.
- `modulos/portalpago` — **Portal de Pago**: Es la liga para que los clientes realicen pagos por transferencia.
- `modulos/reportes` — **Reportes**: Permite consultar y exportar reportes operativos y novedades del sistema.
- `modulos/scheduling` — **Planificación y seguimiento de proyectos y tareas**: Es el módulo para organizar proyectos y tareas del ISP en un solo lugar.
- `modulos/smartimportexport` — **Importación y Exportación de Datos**: Herramienta para cargar o descargar grandes volúmenes de datos desde o hacia el sistema.
- `modulos/talento` — **Talento**: Gestión del personal de campo y sus labores.
- `modulos/tickets` — **Tickets (soporte)**: Es el módulo que gestiona las solicitudes de asistencia de los clientes del ISP.
- `modulos/usuarios` — **Usuarios**: Administración de cuentas de acceso y roles del personal en MegaISP.
- `modulos/vendedores` — **Vendedores**: Administrar la fuerza de ventas del ISP, comisiones y prospectos.
- `modulos/voice` — **Módulo Voice**: Es el conector del sistema con el servicio telefónico.
- `modulos/voip` — **VoIP**: Módulo para gestionar troncales SIP de manera centralizada.
- `modulos/warroom` — **War Room**: Es la sala de juntas digital para monitorear el negocio en tiempo real.
- `modulos/whatsappagent` — **WhatsApp Agent**: Es el sistema de mensajería WhatsApp de la empresa.
