# Avatares de las terminales de la Torre (#430)

Coloca aquí los PNG de cada worker, **nombrados por slot** (no por nombre):

- `wt-1.png` → Maya
- `wt-2.png` → Leo
- `wt-3.png` → Sofía
- `wt-4.png` → Iván
- `wt-5.png` → Nora
- `wt-6.png` → Beto
- `supervisor.png` → supervisor (Thomas T), nodo superior

Convención:
- El avatar va por **slot** (`wt-K`), no por nombre → renombrar un worker (en
  `config/circuito.php` o en la Torre) NO cambia su cara.
- Formato recomendado: PNG vertical (~3:4), fondo suave, medio cuerpo, mismo
  ángulo/composición para toda la serie.
- Mientras falte un `wt-K.png`, la tarjeta cae automáticamente a
  `avatar-placeholder.svg` (no truena).
